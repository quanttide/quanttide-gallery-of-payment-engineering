# 代金券：把公司的服务能力变成内部可定价的资源

代金券不是促销券，是考核与教育体系的定价机制。它要解决的问题是：成员做的事值多少、公司提供的专家资源值多少，两边用同一把尺子量。本案例按需求、意图、规格三段记录这套规则的业务意图与可判定的写法。

## 需求

### 业务意图

公司同时向两类主体提供服务：对外收客户的钱，对内给成员定价。内部没有货币，于是需要一个记账单位，把「成员贡献」与「公司资源」放进同一套账里。

代金券承担两件事：**买得到东西**——成员用它购买专家资源（一对一咨询）与额度（超出限额的提交）；**挣得到东西**——成员通过课堂实训任务、众包交付、代表评审、决议撰写与成果验收挣券。两个方向必须都有，否则券要么是空头承诺，要么无处可用。

一层隐含的结构是三段式计价：**现金 > 代金券 > 内部积分**。现金层对外、暂不对内开放；代金券在公司内部有效，可兑换公司的商业服务；积分是最轻的一层，用于内部零散激励。三层之间的换算关系就是这套制度的骨架。

### 冲突

**券不是现金，却要对客户的钱定价。** 客户出 100 元，内部折算成 1000 元代金券预算——放大十倍。放大倍数是这套规则里最容易被误解的一处：它意味着券的购买力不等于面额，只等于公司愿意让出的服务量。

**基础服务与增值服务必须分开。** 公司指定的活动属基础服务，不需要券；超出能力或超出额度的需求才用券购买。这条分不清，成员会把基础服务也当成要付代价的事。

**激励对象在变。** 规则起初面向个人激励，其后要转向组织层面。同一个券制在两种对象上意味着不同的发放权与核销口径。

**没有外部锚。** 券的价值靠内部价目维持——一对一咨询按职级定价、日常课程按次定价、任务按件定价。价目一改，所有存量券的实际价值随之变化。

## 意图

### 规则

1. **一个定价单位**：代金券是内部唯一的服务计价单位，不用现金、不用积分直接计价。
2. **两侧对称**：凡是能用券购买的服务，都要有对应的挣取渠道；凡是能挣券的行为，都要有花得出去的地方。
3. **不以现金兑回**：券只能兑换服务或额度，不能兑回现金；对外报价与对内券额之间有固定放大倍数。
4. **分基础与增值**：公司指定的活动属基础服务，不需券；超出能力或额度的需求用券购买。
5. **按件与按次定价**：任务按件（如一个课堂实训任务一个价）、服务按时长（一对一咨询按职级分档）、课程按次。
6. **发放权归公司方**：按制度发放，或由管理者按政策需求当场发放；两种走法都须留下可核对的凭据。
7. **层级不跨级**：现金、券、积分三层之间只能按声明过的换算规则兑换，不允许临时比价。
8. **可转赠需先立规**：券在成员之间转让，必须有明确上限与登记方式，否则等于变相发钱。

### 形式化规则

```text
对象：券 C，服务 S，任务 T，成员 M，核算主体（公司 / 组织）

定价
  price: S → 券面额       服务按时长与职级定价
  reward: T → 券面额      任务按件定价
  两侧取值域由同一份价目表给出

兑换
  use:  (M, C) → S        成员用券购买服务
  earn: (M, T) → C        成员完成任务获得券
  放大: 对外金额 × 倍数 = 内部券额，倍数由公司设定，单点可改

约束
  K1 对称：可购买的服务集合非空，可挣取的任务集合非空
  K2 不可兑回：不存在 券 → 现金 的兑换路径
  K3 分层：现金、券、积分三层，换算规则显式声明，不临时比价
  K4 边界：基础服务不在 price 的定义域内
  K5 凭据：每次发放有唯一编号与凭据，可回溯到定稿的价目条目
  K6 转赠：允许转赠时须有上限与登记，否则视为不合规
```

## 规格

### 自然语言描述

规则落成四张表，任何一次发放或核销都要能指回其中一条：

1. **价目表**：服务与时长、职级对应的券额；课程按次；任务按件。价目表是唯一的定价依据。
2. **挣取表**：行为与券额，例如完成一个课堂实训任务、完成一次代表初审、通过一次评审、撰写一次决议、验收一次成果。
3. **边界表**：明确哪些属基础服务不收费，哪些属增值服务需用券。
4. **凭据规则**：一笔发放一条记录，含接收人、金额、事由、发放权人、对应价目条目；一笔一号。

三段式换算写成一处：对外金额与内部券额的放大倍数、券与积分之间的兑换率，各只在一个地方声明，改动留痕。

### YAML 描述

```yaml
定价:
  服务:
    - 对象: 一对一咨询
      计价: 按小时
      分档: 按职级，从高到低多档
    - 对象: 日常课程
      计价: 按次
  任务:
    - 对象: 课堂实训任务
      计价: 按件
    - 对象: 众包交付
      计价: 按项目额度
    - 对象: 代表初审 / 评审 / 决议 / 验收
      计价: 按次

换算:
  对外金额 → 内部券额: 固定倍数，单点声明
  券 → 积分: 规则待定
  券 → 现金: 不允许

边界:
  基础服务: 公司指定活动，不需券
  增值服务: 超出能力或超出额度的需求，用券购买

凭据:
  一笔: 编号、时间、接收人、金额、事由、发放权人、对应价目条目
  编号: 日期加序号，一笔一号
  校验: 合计 = 按接收人汇总之和

不变式:
  - 可购买服务非空，且每条服务都有对应价目
  - 可挣取任务非空，且每条任务都有对应券额
  - 无任何路径把券兑回现金
  - 基础服务不出现在价目表内
  - 每笔发放可回溯到定稿的价目条目
```

## 现状与缺口

规则目前只以口述形式存在于日常沟通中，价目、边界、换算倍数都没有成文定稿。实测一个两个月余的窗口：发放十余笔、合计数千元，按事由分课题与评审占多数、教学与交流次之，文书与决议、问答激励零星若干；其中仅极少数注明计入账本。

四条缺口：价目未成文，同一服务出现过不同价位；券与积分的兑换规则未定；放大倍数只在口头说明里，没有声明处；核销没有回执路径，券兑了什么服务无从查证。

所以现在的代金券处在「有定价实践、没有定价制度」的阶段。要让它是可审计的账，先要成文的三件：价目表、边界表、换算声明。
